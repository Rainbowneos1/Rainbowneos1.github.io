# 游戏规则
================================================================================
                        骰子英雄 - 双骰策略游戏
                           游戏规则说明
================================================================================

欢迎来到《骰子英雄》！这是一款在控制台或网页上进行的单人策略游戏。
你将操控两枚可以自定义的骰子，在九个回合内收集资源、购买强力骰面
和英雄卡牌，最终冲击最高分数！

--------------------------------------------------------------------------------
一、游戏简介
--------------------------------------------------------------------------------
你拥有左右两个骰子，每个骰子有六个面。游戏开始时，骰面上已经有一些
基础的资源面（红色、蓝色、金币、分数）。每回合你可以投掷骰子获得资
源，然后用资源去商店购买新骰面替换旧面，或者购买英雄卡牌获得强力效
果。合理规划资源和骰面构成，是赢得高分的关键。

--------------------------------------------------------------------------------
二、界面速览（网页版）
--------------------------------------------------------------------------------
游戏界面分为几个区域：
  - 顶部栏：显示当前回合、阶段和当前分数。
  - 资源面板：显示你拥有的红色资源、蓝色资源、金币、锤子轨道以及各
    自的存储上限。
  - 骰子展示区：左右两个骰子的六个面，每个面用彩色圆形表示资源。
  - 支援能力区：显示本回合可以发动的支援英雄（如长老、银鹿等）。
  - 已购买英雄：按顺序列出你已获得的英雄卡牌。
  - 消息提示：屏幕右上角会弹出获得资源、触发效果等提示信息。

--------------------------------------------------------------------------------
三、核心规则
--------------------------------------------------------------------------------

3.1 骰子与骰面
  - 你拥有左骰子和右骰子，每个骰子有六个面。
  - 初始12个面为：1个红色资源、1个蓝色资源、2分、9个1金币。
    它们会被随机分配到两个骰子上。
  - 游戏过程中，你可以通过商店购买新面替换旧面，逐渐优化骰子。

3.2 资源与存储上限
  - 红色资源（上限6）和蓝色资源（上限6）：用于购买英雄和骰面。
  - 金币（上限12）：用于在骰面商店消费。
  - 分数（无上限）：游戏结束时计入总分（英雄卡牌额外提供分数）。
  - 锤子（特殊）：见后文“特殊机制”部分。
  - 注意：超出上限的资源会直接损失，请合理规划！

3.3 回合流程
  游戏共进行9个回合。每回合分为四个阶段，必须按顺序执行：
    （1）掷骰子阶段
    （2）支援阶段
    （3）主要行动阶段
    （4）额外行动阶段

3.4 掷骰子阶段
  - 在此阶段，你将同时投掷左右两个骰子，重复4次。
  - 每次投掷都会随机命中每个骰子的一个面，并获得该面上的资源。
  - 如果投掷结果中包含“三倍”面，则会将另一个面的产出翻3倍。
  - 如果两个面都是“三倍”，则无任何收获。
  - 掷骰时，界面上会高亮命中的骰面，并显示第几次投掷的结果。

3.5 支援阶段
  - 如果你购买了拥有“支援能力”的英雄（长老、银鹿、猫头鹰），
    它们会在每个支援阶段可用。
  - 你可以自由选择发动顺序，也可以提前结束该阶段。
  - 常见支援能力：
      · 长老：支付3金币 → 获得4分（金币不足时禁用）。
      · 银鹿：选择左或右骰子，单独投掷1次，获得其产出。
      · 猫头鹰：三选一获得1红、1蓝或1金币。

3.6 主要行动阶段
  你可以选择执行以下行动之一，或者跳过：
    【进入骰面商店】用金币购买新骰面，替换一个已有骰面。
    【购买英雄卡牌】用红/蓝资源购买英雄，获得分数和效果。
  注意：该阶段只能选择一项行动，请谨慎决定。

3.7 额外行动阶段
  如果你拥有至少2个红色资源，可以支付2红进入额外行动阶段。
  你可以执行与主要行动阶段相同的操作，或选择跳过。
  如果跳过，会返还2个红色资源。
  如果红色资源不足2，或资源不足以进行任何有效行动（红=2且蓝=0
  且金币<2），该阶段会自动跳过。

--------------------------------------------------------------------------------
四、骰面商店
--------------------------------------------------------------------------------
在骰面商店中，你可以花费金币购买新骰面，并选择自己骰子上的一个面
进行替换（旧面永久移除）。

部分骰面是“限购”的，整局游戏只能购买一次，购买后会从商店中消失。
同一次进入商店时，不能购买两个完全相同的面。

商店骰面列表（金币价格）：
  - 普通面（可多次购买）：
      · 3金币（2金）         · 1蓝色资源（2金）
      · 4金币（3金）         · 1红色资源（3金）
      · 2分数+2金币（5金）   · 2蓝色资源（6金）
      · 2红色资源（8金）     · 4分（8金）
  - 限购面（仅一次）：
      · 6金币（4金）         · 1红色资源+1分（4金）
      · 1蓝色资源+2金币（4金）· 三选一：1红/1蓝/1金币（4金）
      · 1红+1蓝+1分+1金币（12金）
      · 2蓝色资源+2分（12金） · 6分（12金）
      · 三选一：2红/2蓝/2金币（12金）

三选一面：投掷到该面时，需要从选项中即时选择一种资源获得。

--------------------------------------------------------------------------------
五、英雄卡牌
--------------------------------------------------------------------------------
英雄卡牌需要用红色资源和/或蓝色资源购买，可以重复购买同一英雄。
购买后立即获得卡牌上的分数（游戏结束时计入总分），并触发效果。

英雄列表：
  长老（1红）    0分   支援：支付3金→4分。
  野灵（1红）    2分   立即：获得3蓝+3金。
  猫头鹰（2红）  4分   支援：三选一获得1红/1蓝/1金。
  米诺陶（3红）  11分  无效果。
  戈尔贡（4红）  14分  无效果。
  深渊之镜（5红）16分  无效果。
  斯芬克斯（6红）10分  立即：选择一骰子，单独投掷4次并收获。
  九头蛇（5红+5蓝）26分 无效果。
  巨蟹（6蓝）    8分   立即：两骰子同时投掷2次并收获。
  隐形头盔（5蓝）4分   立即：获得一个“三倍”面替换某个面。
  船夫（4蓝）    12分  无效果。
  萨提尔（3蓝）  10分  无效果。
  银鹿（2蓝）    2分   支援：选择一骰子单独投掷1次。
  宝箱（1蓝）    2分   立即：红/蓝上限+3，金币上限+4。
  锤子（1蓝）    0分   立即：获得锤子轨道（详见特殊机制）。

（注：购买时需要满足资源要求，资源不足的英雄会显示为不可选。）

--------------------------------------------------------------------------------
六、特殊机制
--------------------------------------------------------------------------------

6.1 三倍面（×3）
  - 只能通过购买“隐形头盔”英雄获得。
  - 当投掷结果中包含一个三倍面和一个普通面时，普通面的所有产出
    都会乘以3。如果是三选一面，会先选择资源再乘3。
  - 如果两个面都是三倍，则无任何收获。
  - 三倍面本身不提供任何资源。

6.2 锤子轨道
  - 购买“锤子”英雄后，你会获得一个初始为0、上限+30的锤子轨道。
    再次购买“锤子”可使上限再+30。
  - 以后每当你获得金币时（通过骰子、英雄等），都可以选择将其中
    一部分金币转换为等量的锤子进度（不超过当前轨道上限）。
  - 锤子轨道达到15时，立即获得10分；达到30时，立即获得15分。
    之后每达到15的奇数倍（45、75…）获得10分，偶数倍（60、90…）
    获得15分。超过上限的锤子将不会增加。

--------------------------------------------------------------------------------
七、游戏结束与计分
--------------------------------------------------------------------------------
9个回合结束后，游戏进入结算界面。
最终总分 = 游戏过程中累计的分数 + 所有已购买英雄卡牌提供的分数。
界面上会展示你的最终骰面构成、英雄购买顺序以及总分。

--------------------------------------------------------------------------------
八、游玩小贴士
--------------------------------------------------------------------------------
  · 初期金币较多，可先购买一些高效金币面（如“4金币”）加速发育。
  · 注意资源上限，尽量在资源快满前消费，避免浪费。
  · 三倍面配合高数值面（如“2红色资源”或“4分”）能瞬间爆发。
  · 支援阶段先发动猫头鹰或银鹿获得额外资源，再决定是否用长老换分。
  · 锤子轨道是一条隐藏得分线，购买越早收益越高。
  · 额外行动阶段相当于用2红换一次行动机会，性价比很高，不要浪费。

祝你好运，打造属于你的最强骰子组合！
